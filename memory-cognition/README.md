# 机的人格塑造——认知和记忆为什么要做分离

这是 MIRROW 中 Memory V2 与完整认知书模块的匿名代码副本。它展示一个持续交流的智能体怎样分别保存「发生过什么」与「目前如何理解自己和世界」，以及两者如何通过来源证据相连。这里没有私人对话、真实词条、数据库或模型凭据。

## 两种不同的责任

| 层 | 回答的问题 | 权威记录 | 改变方式 |
| --- | --- | --- | --- |
| Memory V2 | 哪件事在何时发生、依据哪几条原话？ | 原始消息的来源 ID、不可变事件与追加式延续链 | 新证据追加节点；来源被编辑或删除时失效并重建投影，不暗改旧事件 |
| 认知书 | 智能体现在怎样理解自己、他人和世界？ | 带归属、证据、版本和修订记录的词条 | 新经验可支持、修正或推翻认识；版本冲突拒绝静默覆盖 |

一次经历不自动成为稳定信念；一条当前认识也不能冒充过去原话。检索时，事件摘要用于定位经历，原文锚点用于核对细节，认知词条提供目前的理解。面向智能体的表达可以采用第二人称，但底层来源和主体归属保持独立。

## Memory V2 的几个重点

- **技术盒子不等于事件边界。** 原始消息先按会话与容量切成可复核的处理批次；盒内再按连续语义经历提取事件。同一盒可以有几件事，一件事也可以越过盒界。停顿可辅助切批，但默认不把固定分钟数当作「事情结束」。
- **事件可以延续，而不是被改写。** 跨盒、跨日的后续证据通过追加式连接形成事件链；旧事件及其引用不因新解释被静默覆盖。来源消息被编辑或删除时，相关事件的有效状态会失效，召回不继续把旧摘要当可靠事实。
- **摘要负责定位，原话负责核对。** 日常召回先选相关事件／时期摘要；需要具体细节时才按稳定消息 ID 展开少量原文。主动深搜可以把一个模糊问题拆成几个线索阶段，顺着来源关联，而不是把整天对话塞回上下文。
- **不同来源不混成同一人的经历。** 私聊、主动漫想／哨兵、环境观察及派生群聊材料保留来源身份；没有人类回复，不等于人类赞同。记忆召回有独立诊断与反馈记录，反馈本身不自动改写记忆。

自动总结、混合检索、原文追溯与记忆可视化并非本项目独有；这里更关注处理盒、语义事件、延续链和可修订认知之间的边界。上述能力是模块的工程机制，不是「已经能记住一切」的效果承诺。

## 这份源码包含什么

- `src/memory_v2/`：事件编码合同、来源校验、日结与事件延续、只读召回、原文证据展开、主动分路深搜。
- `src/cognition/`：自我、他者、世界与共同理论的日结提取、审核、写入、手动修订、版本校验、维护记录和读取接口。已结算的漫想事件只作为自我认知材料，不冒充人类伙伴发言。
- `src/self_book/`、`src/world_book/`、`src/scp_encyclopedia/`：认知书的文件存储与检索适配。
- `src/behavior_scheduler/`、`src/context_builder/` 中的少量文件：本次摘录所需的书柜工具与来源文本投影，不是完整聊天运行时。
- `tests/`：完全合成的分路深搜与认知书测试。

主观日记、Affect 情绪账本、Open Loop、完整 Context Builder、会客室、设备感知及 MIRROW 的其他人格器官都不在这次代码包里。这里的 `agent` / `human` / `peer` 是匿名示例身份，不预设多用户服务。

后续迭代与不进入本期的能力列在 [ROADMAP.md](ROADMAP.md)。

## 本地验证

Python 3.11+，先在虚拟环境安装依赖：

```bash
python -m pip install -r requirements.txt
```

Linux/macOS：

```bash
PYTHONPATH=src python -m unittest discover -s tests -p 'test_*.py'
```

PowerShell：

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
python -m unittest discover -s tests -p 'test_*.py'
```

测试使用临时目录、模拟检索和模拟模型，不读取私人资料，也不调用模型 API。认知书可以通过注入自己的每日消息读取器、模型调用器和鉴权依赖独立挂载；Memory V2 仍需宿主提供原始对话 SQLite 与运行调度。本仓库不声称是独立可启动的完整伴侣应用。

## 安全与来源

请把原始对话、词条、向量索引、诊断快照和密钥留在自己的本地数据目录，不提交到公开仓库。本项目的记忆设计参考了 [AionsHome](https://github.com/death34018-hue/AionsHome) 已公开的总结、检索和原文追溯思路；其 MIT 许可声明保留在 `LICENSE-AionsHome.txt`。本仓库其余代码使用根目录 `LICENSE`。事件延续链与分离的可修订认知书是本项目自己的设计方向，不将前述通用能力宣称为独创。
