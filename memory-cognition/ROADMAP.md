# 阶段边界

## 本次：Memory V2＋认知书公开源码

包含不可变事件与来源锚点、追加式事件延续、有限召回／主动分路深搜，以及带证据和版本的认知书。公开源码只附匿名合成测试，不附私人对话或生产数据库。

验收标准：从干净 Python 环境安装最小依赖并通过合成测试；公开文件不含私人数据或凭据；README 明确这不是完整聊天应用，也不宣称旧记忆系统已全面退役。

## V3：长期习惯与生活节律雷达

聚合日常低价值小事，形成有时间范围、样本数量、反例和变化轨迹的习惯／节律／表达模式观察。它只提供可修正的认知候选，不把短暂情绪或一次事件写成稳定特质。试运行与反馈后再决定是否进入认知书及上下文。

## 反馈触发的后续项

- 自动查询规划：只有主动深搜的漏召回主要来自线索拆分困难时，再评估额外模型；当前由智能体明确给出分路线索。
- 情境联想：评估未被明确提及的旧事是否应被轻量激活，优先控制误联想。
- 长事件链压缩：只有链节点增长并出现实际注入超量或关键节点遗漏时才做；底层事件保持不可变。
- 情绪余韵与事件来源关联：待跨日体验反馈证明需要更强因果回指后接入，不从时间邻近直接断言原因。
- 旧记忆系统非事件职责迁移：按实际入口逐项替换与验收，不把事件召回切换等同于旧系统全面退役。
