# 2026-11-21 · 漫想随笔与读后插画

此次更新基于 10 月 25 日的公开版 `8299e03`。升级后可以在「机生活 → 媒体 → 随笔」打开书册。新部署的书册从空目录开始，写成第一篇后就能在这里看到。

## 与上一版相比

- 原来的「关键词扩写」现在叫「随笔」。漫想可以写出有题目和正文的作品。打开书册可以按时间翻页，用题目、关键词或正文搜索，并展开阅读。只有带作品标记的已完成记录会进入书册。
- 写随笔时可以给作品配图。重读随笔时也可以摘一句原文画下来。读后插画归到实际读过的那篇作品，书里会同时显示图和原句。找不到原句、同一句有多个可能位置时，系统跳过这次绑定。
- 漫想选择分享时，聊天里可以收到随笔卡片或读后插画。书册里也保留选择私藏的随笔。配图未完成时仍可阅读已写好的正文。

## 接入自己的插画服务

纯文字使用沿用现有漫想模型设置。需要成图时，在后端 Python 环境中提供一个自己信任的适配函数。例如创建 `ai-chat-backend/local_essay_illustrator.py`，定义 `render(scene: str)`，再在启动后端的 PowerShell 窗口设置下面的环境变量。

```powershell
$env:MIRROW_ESSAY_IMAGE_ADAPTER = 'local_essay_illustrator:render'
```

函数接收一段画面描述，可以同步或异步返回单张 PNG、JPEG 或 WebP 的原始字节。服务地址、鉴权及调用由部署者在适配器内配置。使用外部服务时，该服务会收到传入的画面描述。已有图像经核验和重新编码后保存在本机 `ai-chat-backend/static/essay_illustrations/`。本地适配器示例文件名和成图目录已加入 Git 忽略规则。

发布包只提供这两类漫想插画的接入，不提供预设服务、密钥、形象素材、作品或图片。未接服务也可以使用随笔书册。

## 本次验证

在隔离环境用临时书库验证了空目录、正文搜索和旧联想记录兼容。用模拟模型和本地测试适配器执行真实的写作、重读节点，各得到一张插画。浏览器从接口读取同一篇作品，在正文、原句和聊天插画组件中均成功加载了图片。前端生产构建通过。实际成图效果和费用由部署者选择的服务决定。
