# 2026-10-13：公开应用日常闭环更新

## 本次范围

公开宿主可从空库完成聊天、跨午夜活跃日、约定词预约收尾、Memory V2 编码与日结、三域认知整理、日记和次日上下文延续。页面新增「日常」，包含状态、时段、等待、自动整理、闲时漫想和哨兵开关，以及进度、日记、认知查看、失败重试。

这是独立公开宿主的接线更新，不是私人生产目录的完整镜像。小剧场、小衣柜、游戏等未接入默认应用；会客、淘宝只留接口，原始集成移植自 AionsHome。不会发布身份、设备配置、账号、聊天、模型密钥或私有服务。

## 日期与整理

- 约定词由部署者自己设置，留空关闭。时段支持跨午夜，例如 22:00–03:00；默认等待 30 分钟可修改。等待期间的新消息取消旧预约，新的约定词可再次预约。
- 午夜前的收尾延至午夜，防止同一不可变日期反复关闭和再写入；凌晨未收尾的消息仍属于原活跃日。另有可配置整点兜底换日，默认 06:00。
- 已到期预约在进程恢复后、接受下一条消息前先完成关闭。关闭前停止漫想并冻结真实收尾经历；不把中断当作成功。
- 每日三阶段有独立持久化进度，已完成阶段不会因重试再调用。运行中重启恢复为待处理；来源变化、质量待审或模型失败会保留材料，不假报完成。
- 当前日与上一个会话日保留完整原话；更早日期只有全部阶段通过才退出原话窗口，最近一个较早日以日记补入。失败日期继续保留原话，较远材料通过来源可核验的记忆检索读取。
- 日记不是人格文件；自我、他人和世界认知分别走原有来源核验流程。未分享漫想以带执行和交付状态的内部经历进入日记、自我整理与短期上下文，不伪装成用户听过的话。原始活动来源仍在运行库，未分享事件目前不直接写入聊天 Memory V2 的编码源。

## 上下文与工具

`ContextBuilder.build(..., host_materials=..., host_history=..., host_turn=...)` 提供显式四区入口，沿用所有公开 recipe 名称。宿主只传其确实掌握的来源，缺失设备和模块不隐式探测私人服务。当前应用接入身份、历史、用户状态、认知、记忆、日记、日结交接和漫想经历。

工具说明采用当前注册表的 `pro_guide`，缺少时回退精简说明。参数与执行合同独立；不再在静态前缀预设未注册的相机、玩具等能力。真实工具回执携带独立事件 ID、完成时间、成败和 delivery，并随最终消息持久化，前端可展开工具记录；`ui_only` 不向模型注入结果正文，其他回执带后端来源标记。默认仅注册 `search_memory`，可注入自己的公开工具注册表。

公开调度器仍保留兼容的 `TOOL_CALL` JSON 参数协议，不包含生产私有动作编译器、Sidecar 和设备工具清单；不能只复制某个新版自然语言动作提示词而省略其解析实现。新版可复用的工具引导、回执语义与上下文来源边界已经配套接入。

本地应用在实际 provider 边界保持单一稳定首 system，历史不改说话人；动态事实、工具回执与内部合同使用标明后端来源的传输包。独立 OpenAICompatibleWrapper 的同类投影对已知官方 Pro 路径启用，其他兼容供应商可显式设置 `MIRROW_PUBLIC_MATERIAL_PROJECTION=1` 后自行验证。多模态请求保留原结构。不保证固定 token 数或缓存命中率；没有为验收额外调用真实付费模型。

## 漫想与哨兵

- 漫想决策读取四区完整消息，不再因旧单字符串合同漏掉历史；运行态仍必须位于决策材料末尾并通过校验。正常等待、预计窗口复核、中断取消尾部唤醒沿用现有自主节奏。
- 听歌预计时长仅决定何时开始查回执；仅 `finished` 回执可标记曲终，暂停、未知和断连不是成功。失配、结束、超时明确失败，不重放播放命令。
- GPS 独立样本聚合为移动/停留事件；缓存、倒序样本和持续位移不反复触发同一移动提醒。位置变化只唤醒判断模型，不直接决定发消息。
- 哨兵保留两阶段判断、历史引文的来源与说话人核验、生成后的当前观测复核和聊天抢占。第一阶段的主观联系念头不作为对方的事实；这些检查降低错用观测的风险，不是对自然语言绝不出错的保证。
- 可选旧感知协调器同步结构化决策、位置延迟合并和真实交付回执，去掉统一的旧 30 分钟推送拦截。`on_push` 仅在消息权威存储完成后返回 `True`，`None` 不算已投递。

默认哨兵只知道手动状态及本页面可见性；GPS、心率等需要实际设备适配。模块源码公开不代表新安装已经能读取设备或连接朋友。

## 可选宿主接入

可信本地集成可通过 `app.state.services['context_sources'].register(name, reader)` 提供带来源、时间的只读事实；reader 接受 `query` 和 `active_date`。已确认社交事件可由 `lifecycle.days.register_event(event_id, module, active_date, occurred_at, payload)` 注册，供上下文/日记使用。它不是远程 HTTP 写入口；关闭日期不接受新事件，ID 冲突拒绝覆盖。`payload.cognition_evidence` 必须满足认知模块既有证据合同。

设备快照使用 `app.state.services['sentinel'].register_source(name, reader)`。reader 返回 DataSnapshot 字段字典及真实 `field_ts`，缺失数据保持未知，不放凭据；仅注册接口不自动启用硬件。

音乐接入使用 `host_hooks.configure_music(playback=..., receipt=...)`：playback 返回 `{'success': True, 'music_session_id': '真实会话身份', 'playback': {'duration_sec': ...}}`，receipt 接收 `(session_id, song_id)` 返回真实 `state`。旧布尔 True 不再是足够的播放凭据；宿主还须显式注册音乐 handler 和能力白名单。默认 local_app 不启用音乐节点。
