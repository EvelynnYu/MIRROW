# 独立本地应用

`local_app/` 连接本仓库已有模块，面向一人、一机、一个固定主会话；不是私人生产应用的完整镜像。生产专属服务不随复制过程发布。公开版从空数据启动，身份在界面配置，模型密钥只在后端保存。

## 安装

Python 3.11+ 与支持 Vite 8 的 Node.js（建议 Node 22.12+）。在本仓库根目录：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r local_app/requirements.txt
Copy-Item .env.example .env
# 在本机编辑 .env 的 MIRROW_API_BASE、MIRROW_MODEL、MIRROW_API_KEY。
cd wander_frontend
npm ci
npm run build
cd ..
python -m local_app
```

访问 `http://127.0.0.1:8765`，填写身份与人格。macOS/Linux 使用 `source .venv/bin/activate` 和 `cp .env.example .env`，其余命令相同。首次安装不需要复制任何旧数据库。

使用自己的 OpenAI 兼容模型端点；API 根地址通常以 `/v1` 结尾，也接受完整 `/chat/completions` 地址。此版是非流式文本传输，不保证所有供应商的扩展参数均兼容。模型请求、漫想与整理会产生供应商费用；测试不代表已经验证你的供应商效果。端点和密钥不返回给前端。

只安装 `local_app/requirements.txt` 即可运行核心宿主；根依赖文件还包括可选向量模型、感知、浏览器等模块依赖。默认宿主不会自动注册这些外部能力。

## 已接通的功能

| 功能 | 实际数据与执行 |
|---|---|
| 聊天 | 固定会话与 SQLite 消息权威；相同请求 ID 幂等，进程中断不自动重放模型调用 |
| 工具 | 既有 BehaviorScheduler 的 legacy 命令/执行链；默认仅注册本地 `search_memory`，没有文件、设备或浏览器控制 |
| 记忆 | Memory V2 技术分批、严格来源校验、overflow 组装、质量门槛、事件存储、日结与带来源召回；不是用文本搜索伪装长期记忆 |
| 认知 | 三域认知书真实接口与手动日整理；页面提供整理入口，完整词条管理仍使用模块 API |
| 漫想 | 原有持久化计划、节点、复核、结算、自省、愿望与分享回执；默认白名单为关键词联想、回看已编码记忆、自省 |
| 前端 | 聊天、身份、记忆与来源、整理状态、漫想日志、许愿板与评论线程 |

主聊天使用已冻结的消息时间、实际召回和认知材料；provider 边界保持稳定人格/工具合同首 `system`，动态材料标明后端来源，不冒充用户原话。本地结构测试不证明任何供应商的实际缓存命中率。

点击「开启闲时漫想」才开始模型规划。模型在可用事件内决定活动及正常等待时间，技术校验与故障退避仍由运行时负责。发消息、改设定、点击停止都会结束当前闲时段；再次闲时可手动开启。正在执行的节点先完成真实收尾，停止可能等待模型超时，不会立刻伪造完成。重启不会自动开始付费漫想，需要再次明确开启；数据库中的运行身份和未来到点保留。

当前公开宿主按本机自然日记录 `active_date`；没有生产专属的跨午夜手动话题日。当前日保留原始对话，记忆/认知整理仅接受昨天及更早日期。质量待审或模型失败不宣称整理完成；已提交批次在重试前校验并跳过。不要通过修改数据库把旧日期重新变为写入日。

## 独立模块与未接入能力

共享耳蜗、共域／朋友圈、硅基感知、小红书只读适配、其他工具与配方已经按各模块范围公开，但并未全部接入此默认宿主。按各自 README 配置并提供真实回执后才能启用。小红书没有预置设备、账号或登录态。

会客与逛淘宝仅保留单节点活动接口，原始集成移植自 AionsHome，不提供其私人实现。群聊传输、语音全链路、私人设备服务及生产专属功能不由本应用假实现。

## 数据、安全与升级

数据默认保存在根目录 `local-data/`，代码与数据分离；`.env`、数据库、认知书和日志均不入 Git。不要把 `MIRROW_APP_DATA_DIR` 指向另一个部署或私人生产库。备份须在停止进程后复制自己的数据目录和 `.env` 到私密位置；不要上传备份。

只使用默认 loopback 启动入口、单 worker。应用带同源与 Host 检查，但不是公网鉴权系统，不能改成 `0.0.0.0`、直接开放端口或配置公网反代。不会在启动时主动采集麦克风、相机、心率、浏览器或定位。

本次统一移除了公开源码中的私人显示名称和设备默认值。共域参考包的主人 actor 改为通用 `human`；机 actor `k` 是不带展示姓名的既有协议标签，音乐模块也保留该兼容标签。**共域已有部署不能直接把新源码覆盖到旧数据上**：先保留旧版本与离线备份，在自己的私有迁移工具中映射本家 actor、外键、资料缓存和宿主鉴权，再跑模块测试。本仓库不自动迁移旧数据库或替部署者重写身份。
