# 公开应用发布核验

本次在独立公开副本中增加本地聊天宿主和 React 页面，没有复制生产数据、配置或私有 Git 历史。

## 已验证

- 独立新 Python 虚拟环境安装最小宿主依赖；空库启动，不发生模型请求。
- 固定会话、原始消息原子保存、请求幂等、模型失败、进程中断状态、同源/Host 边界。
- 实际 provider 输入中唯一稳定首 system、动态来源包、用户消息不重复；没有验证真实供应商缓存命中率。
- 真实 Memory V2 分批/严格解析/来源校验/事件提交/召回路径；测试日结外部模型回调为模拟，不宣称真实模型质量。
- 真实漫想计划、节点、复核、结算、分享与同源消息落盘链路，模型响应为合成数据。
- 桌面与手机尺寸的聊天、设定、空检索、漫想日志与许愿板浏览器测试；三个公开前端均可构建。
- 记忆认知与音乐模块的离线测试；共域纯领域测试可部分运行，但完整共域宿主集成测试仍依赖未公开的认证/会客运行时，不能把缺少该依赖宣称为全量验收。

## 脱敏范围

文本检查涵盖已知个人称呼、私人身份片段、设备默认值、凭据形态、非示例网络地址、本地路径和运行文件。已知个人称呼及凭据形态检查零命中；通用扫描剩余命中逐项核对为第三方文档占位符、通用示例路径、浏览器版本或合成测试地址。第三方署名和许可证保留。

同时检查演示图片；音乐聊天预览由当前匿名演示界面重新渲染，不使用真实聊天、头像或账号数据。依赖、构建产物、测试截图、运行数据库、环境文件和私有审计规则不进入发布变更。

这不是数学上的“绝无泄漏”证明。普通提交只清理当前文件，不会擦除历史提交、缓存、分叉或他人的副本；真实密钥若曾外泄必须在服务商处撤销，改仓库内容不能代替撤销。

## 尚未宣称完成

没有使用真实模型 API、真人设备、登录账号或跨站服务验证；未提供生产应用全部功能。共域角色命名存在显式兼容性变化，见 [应用指南](LOCAL_APP.md#数据安全与升级)。外部能力仅在部署者实际接通并取得回执后启用。
