# 11 月 28 日 · 漫想、安卓桌面与小红书私信

对比 11 月 22 日的漫想 V3，这次沿用同一套规划器、事件库和上下文。已有部署可以保留本机数据并升级前后端。

## 漫想里有什么变化

- 写随笔时，可以先查找并阅读相关旧作，再决定另起一篇或接着写。续篇会保留上一篇的作品 ID，重名作品在保存时区分。打开「机生活 → 媒体 → 随笔」就能沿篇章关系阅读。旧的独立作品仍可直接打开。
- 自主浏览小红书时，规划能提前确定推荐、搜索、主页或本账号收藏里的阅读目标。读主页时可以沿上次的位置继续。图集按实际读到的页面取材；浏览途中确实看见未读提示才顺路核对。评论、艾特和私信分别取得来源和结果。
- 节点选项无效或可重复读取暂时受阻时，支持当场一次纠正或重读。发生了什么会随节点收据保存，可在事件概览回看。已经提交的外部动作沿原收据核验，以免重复发送。
- 运行状态能区分活动中、等下一节点与休息间隔。逛书柜时，界面依据当前节点真正读到的来源展示「随笔」或「收藏」。

## 安卓桌面小组件

手机桌面长按并添加 **MIRROW 漫想**。默认占 4 × 2 格，可缩放。桌面显示最近所见活动、同步时间和主要心情类别。点击活动或心情可打开应用内的对应面板。主会话正在回复只在近期观测有效时展示。断连会标明上次所见，可点刷新。

小组件读取后端的窄状态接口。主聊天消息、联系人和私信正文都不进入这两个接口。界面配有通用活动图；个人头像由各自手机在运行时提供。

## 小红书私信

配置本机账号和专用 Android 设备并启用后，漫想可选择查看个人私信。新联系人先在「收藏 → 🍠 私信」核对该批来信，再决定批准、拒绝或拉黑；可将已核对的平台身份绑定到本机他者书。已绑定联系人和自行指定的伙伴账号按核验后的身份处理。AI 可以回复，也可以读后离开。回复提交后用真机可见结果核验，结果未知时保留原收据。

## 已部署用户怎么更新

1. 在独立目录更新前后端源码，保留自己的环境配置和运行数据库。重启自己的后端，重新构建前端。有旧随笔的部署无须重生成作品。
2. 需要小组件时，按[部署说明](DEPLOYMENT.md)重新构建并安装 Android 主应用，先在应用内连通自己的后端，再添加小组件。
3. 需要私信时，同步更新文字输入辅助程序，再按[小红书配置步骤](DEPLOYMENT.md#小红书私信)绑定自己的账号与专用设备。仅使用桌面小组件时无需配置小红书。
