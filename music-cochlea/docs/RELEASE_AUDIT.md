# 发布审计 · 2026-10-03

## 分发范围

只导出现役耳蜗领域、音乐 UI、Android 音乐控制、已公开的基础工具／共享状态，以及明确的宿主协议和可运行示例。不复制整机聊天、人格、自我书、Memory V2 数据库、账号状态、历史图片、录音、日志、部署配置、签名、私有 Git 历史。退役全局音乐模式与无调用的旧歌单分析器不分发。

`owner / k / shared` 是中性歌单归属协议。私有记忆检索、场景、认知整理、完整漫想调度通过文档接口接入；默认示例无 AI 大脑，不伪造认知更新或播放。

## 已验证

- 后端 **81 项离线测试通过**：真实 HTTP 被测试门禁拒绝，使用临时 SQLite／假设备观察。覆盖现役领域逻辑，以及示例认证、卡片消息持久化、音乐 Relay 收据与异步推歌补回原占位、分享计数和不自动播放。
- 前端 TypeScript 检查与 Vite 生产构建通过；Playwright 使用实际音乐组件验证虚构链接识别→卡片保存→随消息发送→删除。
- Android debug 构建与单元测试编译通过；通过 JUnitCore 验证 **7 项**身份／链接／启动确认测试。此公开示例未做真机安装或曲尾播放验收。
- 两轮独立只读复审核对依赖接线与隐私范围；发现的 AionsHome 归属遗漏、eryu MIT 误标、旧未调用文件和示例路径已修正。
- 公开文本与路径扫描：凭据模式、私钥、个人路径、非回环地址、MAC 与异常二进制。私有侧另核对个人称呼、设备标识和历史地址，没有把这些检查词写入公开文件。
- 三张发布 PNG 已人工查看，只包含虚构歌曲／歌词／聊天和通用品牌文字；EXIF、文本／作者／注释等元数据检查通过。没有使用真实界面截屏、照片或歌曲音频。
- Gradle Wrapper JAR 使用固定 SHA-256 核对；其余构建产物不进入分发。全文许可证与文件头归属已核对。

## 发布门禁

`scripts/check_release.py` 审计可分发文本、路径名与 PNG/JPEG/WebP/GIF 元数据；已有 Git 仓库时检查跟踪范围及暂存内容与当前文件一致性。`--strict-tree` 额外拒绝非空运行产物目录。

`RELEASE_MANIFEST.json` 记录每份可分发文件的 SHA-256。`scripts/pack_release.py` 只接受与新清单完全一致的源码，只将清单文件及清单自身写进 ZIP，并重开 ZIP 校验条目集合、CRC 和逐文件哈希。打包使用 `python -B`，避免在干净树写入 Python 缓存。

发布包不带 `.env`、数据库、Cookie、APK、签名、依赖目录、构建目录或 Git 历史。GitHub 初次提交同样不可使用强制添加忽略文件；后续自行运行、编辑或提交后，应重新执行审计并生成清单。

## 仍需安装者验收

真实网易云账号、VIP／版权、Windows 媒体会话、Android 通知访问和后台限制、各厂商曲尾保护与手机网络连接，不能用离线测试代替。前端必须是自己控制的受信任来源；公网用 HTTPS，令牌不提交。日整理和自我书写入需要自己的 LLM 与真实宿主消费回执。

本审计针对这一版选定分发内容，不承诺未来改动、运行数据或未审计 Git 历史自动安全。追加到既有 MIRROW 公开仓库时，只提交 `music-cochlea/` 模块及根目录入口／许可说明；既有公开历史不在本次全量审计范围。
